# Global Auto Translator (RimWorld 1.6 + локальный LLM)

Глобальный автопереводчик: переводит названия/описания любых модов и текст интерфейса
на русский через OpenAI-совместимый эндпоинт (CLIProxyAPI, Ollama, LM Studio),
кэширует всё локально и умеет экспортировать готовые XML локализации.

---

## Архитектура: три слоя

| Слой | Где | Что ловит | Цена |
|---|---|---|---|
| **L1** | `DefPostProcessor` | `label`, `description` и ещё ~16 строковых полей всех Defs | 0 во время игры |
| **L2** | `LoadedLanguage.TryGetTextFromKey` | все Keyed-строки интерфейса | один lookup по словарю |
| **L3** | `Widgets.Label` (выключен) | хардкод в C# чужих модов | только чтение кэша |

Критичное правило: **L3 никогда не шлёт запросов и не ставит в очередь.**
`Widgets.Label` вызывается тысячи раз в секунду — любая регулярка там даст микрофризы.

Сеть живёт только в фоновых потоках (`TranslateWorker`). Главный поток никогда не ждёт ответа:
нет перевода — показывается оригинал, при следующем запуске будет русский.

## Сборка

1. Установи **Visual Studio 2022 Community** → рабочая нагрузка «Разработка классических приложений .NET».
2. Открой `Source/GlobalAutoTranslator.csproj`.
3. **Обязательно** поправь в `.csproj` строку `<RimWorldManaged>` под свой путь игры:
   ```
   ...\steamapps\common\RimWorld\RimWorldWin64_Data\Managed
   ```
4. `Build` → результат сам ляжет в `Assemblies/GlobalAutoTranslator.dll`.
5. Положи всю папку `GlobalAutoTranslator` в `steamapps\common\RimWorld\Mods\`.
6. В игре включи **Harmony**, затем этот мод (лучше сразу после Harmony, до всего остального).

Если NuGet недоступен, вместо `PackageReference Lib.Harmony.Ref` добавь ссылку на `0Harmony.dll`
из папки мода Harmony с `Copy Local = False`. **Никогда не клади `0Harmony.dll` в свой `Assemblies/`.**

## Настройка прокси

Файл `proxy/config-payload-snippet.yaml` — допиши его содержимое в конец своего `config.yaml`.
Без этого Gemini жжёт ~800 reasoning-токенов на каждый батч впустую.

Проверка: `proxy/test-batch.bat` → в `usage` должно быть
`prompt_tokens + completion_tokens == total_tokens` и никакого `reasoning_tokens`.

Запуск прокси: `proxy/run-proxy.bat` (поправь `PROXYDIR` внутри).

---

## Первый запуск

1. Запусти прокси, проверь `test-batch.bat`.
2. Запусти RimWorld → Настройки → Моды → Global Auto Translator.
3. Жми **«Проверить связь и качество перевода»**. Нужны три `[OK]`.
4. Жми **«Перевести все Defs сейчас»** и оставь игру на меню. Смотри статус-строку.
5. Когда очередь опустеет — **«Сохранить кэш на диск»**, потом перезапусти игру.

Кэш лежит здесь:
```
%USERPROFILE%\AppData\LocalLow\Ludeon Studios\RimWorld by Ludeon Studios\GlobalTranslator\cache\
```
Это обычные TSV-файлы — можно открыть блокнотом и править руками.

## Экспорт в настоящий мод-перевод

Кнопка **«Экспортировать кэш в мод с XML-переводом»** собирает папку `GeneratedRussian`
с нативными `DefInjected` и `Keyed` (UTF-8 с BOM). Скопируй её в `Mods/` и включи
**самым нижним** в списке модов.

После этого перевод работает штатными средствами игры — без сети, без Harmony,
без этого мода вообще. Можно отдавать друзьям.

Важно про Keyed: экспортируются только те ключи, которые игра реально запрашивала
в текущей сессии. Чем больше играешь до экспорта — тем полнее выгрузка.

## Защита от битых переводов

`PlaceholderGuard.Validate` отбрасывает строку, если:

- набор `{...}` / `<...>` / `[...]` / `\n` не совпал с оригиналом до символа;
- перевод длиннее оригинала больше чем в 3.5 раза (модель начала объяснять);
- есть ``` или префикс «Перевод:»;
- не сходится количество `<color` и `</color>`.

Отброшенное уходит в карантин и остаётся на английском. С включённым подробным
логом причина пишется в лог игры. Кнопка «Сбросить карантин» — повторить попытку.

## Честные ограничения

- **Падежи.** `{PAWN} повержен(а). Причина: {0}` — это обход, а не решение.
  Русская грамматика требует согласования, которого движок не даёт. Потолок принципиальный.
- **Текст на текстурах** не переводится вообще.
- **Строки, склеенные в C# по кускам**, ловятся только слоем 3 и только если тот же текст
  уже попадал в кэш целиком.
- **CLIProxyAPI + Antigravity — это не локальная модель.** Локальный только прокси;
  текст уходит в облако Google. Для полной автономности поставь Ollama и укажи
  эндпоинт `http://127.0.0.1:11434/v1/chat/completions`, модель `qwen2.5:14b-instruct`.
- **В Steam Workshop такое выкладывать не стоит** — чужие автопереводы чужих модов без
  разрешения авторов — серая зона. Для себя — без проблем.

## Если что-то не работает

| Симптом | Причина |
|---|---|
| В логе «Не найден LoadedLanguage.TryGetTextFromKey» | Ludeon поменял сигнатуру. Открой `Assembly-CSharp.dll` в ILSpy и сверь имя |
| Ничего не переводится | прокси не запущен или неверный эндпоинт — жми кнопку проверки связи |
| Много «отброшено» | батч слишком большой, модель теряет ключи — снизь до 25 |
| Игра фризит | включён слой 3 — выключи |
| Кракозябры в экспорте | файл открыт редактором без UTF-8, пересохрани в UTF-8 |
